# DNA_protein
DNA 서열을 보고, 서열의 유전적 변이가 단백질의 구조적/기능적 변화(phenotype)로 이어지는 과정을 분석하는 프로그램을 만들어줘.

분석 파이프라인

염기 서열 번역
변이 지점 식별
물리화학적 특성 분석
(bio-python을 사용해 단백질의 분자량, 등전점, 불안정 지수, 지방족 지수, 친수성 지수 등을 계산)
기능적 영향 예측
(Meta AI의 ESM-2 언어 모델을 사용해 치명적인 정도를 예측해줘)
오늘 한 일 한줄 정리: AI(바이브 코딩)을 통한 바이오인포메틱스(DNA 염기서열,protein 기능) 예측을 하는 프로그램을 만들어봤다.
